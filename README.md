# 🛍 E-BAZAR — магазин на GitHub Pages

Магазин: **https://malik-alaska2.github.io/E-BAZAR/**

Работает без сервера: страница, товары и фото лежат прямо в этом репозитории. Ничего не нужно оплачивать и настраивать — GitHub раздаёт сайт бесплатно, и он открывается везде.

Три языка (русский, узбекский, турецкий), цены в турецких лирах ₺, оплата наличными при получении. Заказ уходит менеджеру в Telegram сообщением.

---

## Как приходят заказы

Покупатель набирает корзину, заполняет имя, телефон и адрес, выбирает менеджера (мужской или женский отдел) и нажимает «Отправить заказ в Telegram». Открывается чат с менеджером, где уже готов текст заказа — покупателю остаётся нажать «Отправить».

Менеджер получает сообщение вида:

```
🛍 НОВЫЙ ЗАКАЗ №260729-6947

• Казы — 1 × 650 ₺ = 650 ₺
• Молоко — 1 × 35 ₺ = 35 ₺

💰 Итого: 685 ₺
💵 Наличные

👤 Айгуль
📞 +90 555 000 11 22
🚚 Доставка
📍 Анкара, Чанкая
```

## Как менять товары (админка)

Админка встроена в сам магазин: откройте его и **нажмите 5 раз подряд на логотип** (или добавьте `#admin` к адресу).

### Вход по логину и паролю (основной способ)

Работает на адресе Vercel: **https://e-bazar-sage.vercel.app/#admin**. Вход запоминается в телефоне на 30 дней.

Логин, пароль и ключ GitHub хранятся в скрытых настройках Vercel
(Project `e-bazar` → Settings → Environment Variables):

| Переменная | Что это |
|---|---|
| `ADMIN_LOGIN` | логин админки |
| `ADMIN_PASSWORD` | пароль админки |
| `GITHUB_TOKEN` | ключ GitHub, которым сервер сохраняет товары |
| `SESSION_SECRET` | случайная строка; если поменять — все входы сбросятся |

Чтобы сменить пароль: поменяйте `ADMIN_PASSWORD` в Vercel и нажмите **Redeploy**. Старые входы сразу перестанут действовать.

### Вход по ключу GitHub (запасной способ)

Нужен, только если сервер Vercel недоступен (например, на GitHub Pages). В окне входа нажмите «Войти через ключ GitHub».
Ключ создаётся здесь: https://github.com/settings/tokens?type=beta → доступ только к репозиторию **E-BAZAR**, права **Contents: Read and write**.

Дальше можно:

- **Разделы** — кнопка «＋ Добавить раздел», названия на трёх языках (RU / UZ / TR), порядок стрелками ↑↓, удаление 🗑
- **Товары** — кнопка «＋ Добавить товар»: фото с телефона (📷), цена в ₺, единица (кг / шт / л), раздел, наличие, названия и описания на RU / UZ / TR
- Внизу — **«Сохранить всё 💾»**

После сохранения GitHub обновляет сайт примерно за минуту. Если изменения не видно — обновите страницу.

## Что где лежит

```
index.html      весь магазин: витрина, корзина, оформление, админка
api/            вход в админку по паролю и сохранение товаров (функции Vercel)
assets/         логотип
catalog.json    товары и разделы (обновляется из админки)
photos/         фотографии товаров
```

## Настройки

В начале `index.html` есть блок `CONFIG`:

```js
const CONFIG = {
  currency: "₺",            // валюта
  minOrder: 0,              // минимальная сумма заказа (0 = без ограничения)
  deliveryFee: 0,           // стоимость доставки (0 = бесплатно)
  phone: "+905011153333",   // телефон магазина
  managers: [               // кому приходят заказы
    { username: "yusufabdulloh55555", icon: "👳‍♂️", key: "managerMen"   },
    { username: "Ummumaryam9169",     icon: "🧕",   key: "managerWomen" },
  ],
};
```

## Магазин внутри Telegram

Чтобы магазин открывался кнопкой в вашем боте: **@BotFather** → `/mybots` → ваш бот → **Bot Settings** → **Menu Button** → вставьте адрес магазина.
