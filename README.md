# 🛍 E-Bazar — Telegram-магазин для VPS

Онлайн-магазин с ботом: каталог с разделами, корзина, оформление заказа, админка с загрузкой фото. Три языка (RU / UZ / EN), цены в турецких лирах ₺, оплата наличными при получении. Заказы приходят владельцу в Telegram.

Работает на своём сервере — не зависит от блокировок Cloudflare Pages.

---

## Установка на VPS (одна команда)

Подключитесь к серверу — в панели Hostinger это кнопка **Browser terminal** (или `ssh root@ВАШ_IP`) — и выполните:

```bash
apt update && apt install -y git && \
git clone https://github.com/ВАШ_ЛОГИН/e-bazar.git /root/e-bazar && \
bash /root/e-bazar/install.sh
```

Установщик спросит четыре вещи:

| Что | Где взять |
|---|---|
| Домен | у Hostinger VPS уже есть готовый, вида `srv1234567.hstgr.cloud` — просто нажмите Enter |
| `BOT_TOKEN` | @BotFather → `/newbot` (или `/mybots` → API Token) |
| `ADMIN_CHAT_ID` | @userinfobot пришлёт ваш числовой ID |
| Пароль админки | придумайте сами |

Дальше всё автоматически: Node.js, HTTPS-сертификат (бесплатный, Let's Encrypt), служба автозапуска, настройка бота — вебхук, кнопка меню, команды.

Через 3–5 минут магазин открыт по адресу `https://ваш-домен`, а бот отвечает на `/start` кнопкой «🛒 Открыть магазин».

> Установщик предложит остановить n8n и другие программы, если они занимают порты 80/443.

## Как пользоваться

**Админка** — откройте магазин и нажмите **5 раз подряд на логотип** «E-Bazar» (или добавьте `#admin` к адресу), введите пароль.

Внутри можно:

- **Разделы** — переименовать на трёх языках, менять порядок ↑↓, добавлять, удалять
- **Товары** — загрузить фото прямо с телефона (📷), поставить цену в ₺, выбрать единицу (кг / шт / л), раздел, наличие, описание
- Внизу — **«Сохранить всё 💾»**: без неё изменения не применятся

Фото сжимаются в браузере и хранятся на сервере в `data/uploads/`.

**Заказы** приходят вам в Telegram: список товаров, сумма, имя, телефон, адрес, комментарий. Покупателю, заказавшему из Telegram, автоматически уходит подтверждение с номером заказа.

## Проверка и обслуживание

```bash
systemctl status ebazar      # состояние магазина
systemctl restart ebazar     # перезапустить
journalctl -u ebazar -f      # смотреть логи
```

Диагностика в браузере: `https://ваш-домен/api/diag` — покажет состояние бота, вебхука и пришлёт вам тестовое сообщение в Telegram.

Если меняли токен бота или домен: `https://ваш-домен/api/setup` — перенастроит бота.

---

## Обновление магазина

```bash
cd /root/e-bazar && git pull && bash install.sh
```

Товары, фото и заказы сохранятся — они лежат в `/opt/ebazar/data/` и не затрагиваются.

---

## Настройки магазина

В файле `public/index.html` в начале скрипта:

```js
const CONFIG = {
  shopName: "E-Bazar",
  currency: "₺",       // валюта
  minOrder: 0,         // минимальная сумма заказа (0 = без ограничения)
  deliveryFee: 0,      // стоимость доставки (0 = бесплатно)
};
```

После правки: `systemctl restart ebazar`.

## Что где лежит

```
server.js           сервер (Node.js, без внешних библиотек)
public/index.html   весь магазин: каталог, корзина, оформление, админка
install.sh          установщик
/opt/ebazar/.env    токен бота, ID админа, пароль (создаётся установщиком)
/opt/ebazar/data/   каталог, фото товаров, история заказов
```
